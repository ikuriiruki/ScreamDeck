# ScreamDeck

Stream screamers for Windows: an image, gif or video with sound over your screen and in OBS. Sets fire on a random timer or via a local API (Stream Deck, etc.).

[Download](https://github.com/ikuriiruki/ScreamDeck/releases/latest) · [Docs](docs/README.md)
