# ScreamDeck — документация

[English](README.md)

Приложение для Windows, которое показывает «скримеры» (картинка, гифка или видео со звуком) поверх экрана и в OBS. Скримеры собираются в наборы; набор стреляет по таймеру в случайном интервале, а ещё его можно дёргать по локальному API (Stream Deck, награды Твича и т. п.).

## Установка

1. Скачайте `ScreamDeck_*-setup.exe` из [последнего релиза](https://github.com/ikuriiruki/ScreamDeck/releases/latest) и запустите.
2. Установщик не подписан кодом, поэтому Windows SmartScreen покажет «Windows защитила ваш компьютер». Нажмите **Подробнее → Выполнить в любом случае**.
3. Обновления: Настройки → «Обновления» → **Проверить**. Приложение ищет новую версию в GitHub Releases и ставит её по кнопке «Установить и перезапустить» (подпись обновления проверяется ключом Tauri).

После установки все наборы выключены: скримеры не появятся сами. Включённость наборов по умолчанию не восстанавливается при запуске (настройка «Восстанавливать включённые наборы при запуске» выключена), чтобы автозапуск не пугал, когда стрима нет.

## Как пользоваться

### Клавиша «Стоп»

**`Ctrl+Shift+End`** сразу закрывает текущий скример и очищает очередь. Работает везде, в том числе в игре. То же делает кнопка **Стоп** вверху приложения и в меню трея. Клавишу можно сменить в Настройки → Общее → «Клавиша «Стоп»»; если новое сочетание занято другой программой, появится ошибка, а старая клавиша продолжит работать.

### Скримеры

Вкладка «Скримеры» → **Новый** → выберите файл (PNG, JPG, WebP, GIF, MP4, WebM).

- **Звук:** *Из видео* (только для видео), *Свой файл* (MP3, OGG, WAV, M4A) или *Без звука*.
- **Длительность:** *По длине звука* или *Своя*. Для своей — ползунок или поле в секундах. На ползунке отмечены длины видео и звука, значение к ним примагничивается; зажмите **Ctrl**, чтобы отключить примагничивание. Если показ длиннее медиа, видео повторяется по кругу, а звук играет один раз.
- **Громкость** у каждого скримера своя, **Вписывание:** *Заполнить* (обрезать по экрану) или *Целиком* (прозрачные поля, игру видно).
- **Проверить** показывает скример только на вашем ПК — зрители тестовые показы не видят.

### Наборы

Вкладка «Наборы» → **Новый**. В наборе:

- **Мин. / Макс. интервал** — следующий скример выстрелит через случайное время в этом диапазоне (от 1 секунды до 24 часов).
- **Скримеры · вероятность** — добавьте скримеры и задайте каждому вес; проценты показывают шанс каждого. Один скример может быть в нескольких наборах с разными весами.
- **Доступен через API** — можно ли через API вызывать, включать и выключать этот набор.
- **Случайный** показывает случайный скример из набора только на вашем ПК. **Экспорт** сохраняет набор вместе со скримерами в `.zip`.

Набор включается переключателем. Можно включить несколько наборов — приложение спросит подтверждение и перечислит уже включённые. Скримеры не накладываются: если в момент срабатывания таймера уже идёт показ, срабатывание пропускается.

### Импорт и экспорт

- **Экспорт набора:** откройте набор → **Экспорт**.
- **Экспорт скримеров:** вкладка «Скримеры» → **Выбрать для экспорта** → отметьте скримеры → **Экспорт**; или откройте скример → **⋯** → **Экспорт**.
- **Импорт:** **Импорт .zip** на вкладке «Наборы» или «Скримеры». Сначала приложение покажет, что будет добавлено; уже имеющиеся скримеры пропускаются, а набор с тем же id добавляется копией.

## Настройка OBS

1. Настройки ScreamDeck → «OBS — источник «Браузер»» → скопируйте ссылку (по умолчанию `http://127.0.0.1:7811/overlay`).
2. В OBS добавьте источник **«Браузер»**, вставьте ссылку, задайте размер холста (например 1920×1080). Фон страницы прозрачный.
3. Звук оверлея по умолчанию выключен: скример звучит на ПК и попадает в стрим через **«Звук рабочего стола»**. Включайте «Звук в оверлее» только если не захватываете звук рабочего стола, иначе будет дважды.
4. Экран ПК скрыт от захвата (Windows 10 2004+), чтобы он не дублировал оверлей. Проверьте: кнопка «Тест» в настройках показывает скример и на ПК, и в оверлее. В превью сцены OBS скример должен быть один (из оверлея), без второго от захвата экрана.
5. Игры нужно запускать в режиме **«оконный без рамки»** (borderless windowed): в «полноэкранном» эксклюзивном режиме Windows не рисует поверх игры окна других программ.

## Где хранятся данные

Скримеры, наборы и медиафайлы по умолчанию лежат в `%APPDATA%\com.ikuriiruki.screamdeck`. Путь показан в Настройки → Общее → **Папка данных**: **Открыть в проводнике** открывает её, **Изменить** переносит данные в другую папку (наборы останавливаются, файлы копируются и проверяются, потом старая копия удаляется) или открывает библиотеку, которая там уже есть. Для бэкапа скопируйте эту папку; для переезда на другой ПК — экспорт/импорт или копия папки.

## Если что-то не так

- **Скример не виден поверх игры.** Переключите игру в «оконный без рамки». Проверьте выбранные мониторы в Настройки → Экран ПК.
- **На стриме два скримера (большой и оверлей).** Включите Настройки → Экран ПК → **Скрывать от захвата** (Windows 10 2004 и новее) и проверьте кнопкой **Тест**.
- **По таймеру ничего не происходит.** Набор должен быть включён и содержать хотя бы один скример. После перезапуска наборы выключены, если не включено «Восстанавливать включённые наборы при запуске».
- **«Порт 7811 занят другой программой».** Порт занят, поэтому оверлей OBS и API не работают. Нажмите **Выбрать свободный порт** на баннере и обновите ссылку в OBS. Сам порт никогда не меняется.
- **«Папка данных недоступна».** Папка на отключённом диске или не читается. Подключите диск и нажмите **Повторить** или **Выбрать другую**. Пока папки нет, приложение ничего не записывает.
- **«Библиотека была повреждена — начата новая».** Испорченный файл сохранён рядом, путь к нему указан на баннере.
- **Не удалось назначить клавишу «Стоп».** Сочетание занято другой программой — выберите другое, прежняя клавиша продолжает работать.

## API

Только `127.0.0.1` (порт по умолчанию 7811, меняется в настройках). Запросы с чужим `Origin` (любой сайт в браузере) и с чужим `Host` (DNS rebinding) получают 403; CORS-заголовков нет, так что API работает для локальных программ, но не для веб-страниц.

| Метод | Путь | Ответ |
|---|---|---|
| GET | `/api/screamers` | 200, список `{id, name, kind, durationMs}` |
| GET | `/api/sets` | 200, список `{id, name, enabled, api, size}` |
| POST | `/api/trigger/screamer/{id}` | 202 `{"queued": bool}`; 404 нет такого; 429 очередь полна |
| POST | `/api/trigger/set/{id}` | 202 `{"queued": bool}`; 404; 403 у набора выключено «Доступен через API»; 409 набор пуст; 429 очередь полна |
| POST | `/api/stop` | 204, закрывает текущий скример и очищает очередь |
| POST | `/api/sets/{id}/enable` · `disable` · `toggle` | 200 `{"enabled": bool}`; 404; 403 если API у набора выключен |

`queued: true` значит, что показывается другой скример и вызов встал в очередь (лимит 10, дальше 429). Скримеры не накладываются. Случайный из набора работает и для выключенного набора: «включён» управляет только таймером.

```bash
curl http://127.0.0.1:7811/api/sets
curl -X POST http://127.0.0.1:7811/api/trigger/screamer/ID
curl -X POST http://127.0.0.1:7811/api/trigger/set/ID
curl -X POST http://127.0.0.1:7811/api/sets/ID/toggle
curl -X POST http://127.0.0.1:7811/api/stop
```

## Разработка

Нужны Node (LTS), pnpm, Rust stable, WebView2.

```bash
pnpm install
pnpm build                                        # обязательно до cargo: rust-embed читает ../dist при компиляции
pnpm tauri dev
pnpm test
cargo test --manifest-path src-tauri/Cargo.toml
```

В свежем клоне `dist/` нет, поэтому `cargo test`/`cargo build` без предварительного `pnpm build` не соберутся.

### Как добавить поле в набор

1. Поле в структуре `ScreamSet` в `src-tauri/src/model.rs` (у структуры уже `#[serde(default)]`, у нового типа должно быть значение по умолчанию; старые файлы продолжат грузиться без миграций).
2. Тип в `src/lib/types.ts`.
3. Контрол на экране `src/pages/SetDetail.tsx`.

### Как добавить API-эндпоинт

Маршрут в `router()` и обработчик в `src-tauri/src/server.rs` (защита Origin/Host применяется ко всем маршрутам сама), тест рядом в `mod tests`, строка в таблицу выше и в [README.md](README.md).

### Как добавить язык

Скопируйте `src/i18n/en.json` в `src/i18n/<код>.json`, переведите, подключите файл в `resources` в `src/app/i18n.ts`, добавьте язык в тип `Language` (`src/app/i18n.ts`), в `languageOf` и в переключатель языка `src/pages/Settings.tsx`.
